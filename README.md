# PINTU TEPAT (prototipe demo)

Prototipe karya Tim Polkesraya untuk Tambun Bungai Ideathon 2026, Subtema 2: Bantuan Sosial Non Tunai.

PINTU TEPAT membantu penerima bantuan sosial non tunai yang kartunya bermasalah menemukan pintu yang tepat. Alurnya: pilih gejala, jawab satu sampai tiga pertanyaan, lalu bawa Kartu Rujukan berisi kode pendek tanpa data pribadi. Pendamping mencatat kodenya, dan polanya tampil di papan sinyal untuk koordinator.

Tim: Polkesraya
Ketua: Deddy Eko Heryanto, S.T.
Anggota: Yetti Wira Citerawati SY, S.Pd., S.Gz., M.Pd.

## Batas

- Semua angka di layar adalah data sintetis untuk demo.
- Tidak memproses transaksi, tidak memeriksa saldo, dan tidak terhubung ke sistem pemerintah atau bank.
- Tidak menyimpan data pribadi. Jangan memasukkan PIN, OTP, NIK, atau nomor kartu.
- Tidak berafiliasi dengan lembaga mana pun.
