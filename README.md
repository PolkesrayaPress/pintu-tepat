# pintu-tepat
PINTU TEPAT membantu penerima bantuan sosial non tunai yang kartunya bermasalah menemukan pintu yang tepat. Alurnya: pilih gejala, jawab satu sampai tiga pertanyaan, lalu bawa Kartu Rujukan berisi kode pendek tanpa data pribadi. Pendamping mencatat kodenya, dan polanya tampil di papan sinyal untuk koordinator.
